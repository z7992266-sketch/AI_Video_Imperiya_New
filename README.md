# B2B SAS Control Center

Flutter app (Android) that watches all B2B SAS apps: health checks every minute (Supabase Edge Function + pg_cron), incidents, maintenance mode, biometric + PIN lock.

- App code: `control_center/lib`
- Build: GitHub Actions → Releases (`control-center-v1.0.N`, file `B2BSAS-ControlCenter.apk`)
